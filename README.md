# フランス語クイズ 🇫🇷 (保護者向けメモ)

## v37 パリの冒険・試作品

気球でパリへ到着し、広場から「川沿い」「公園」の2方向を選んで、フランス語を学びながら旅を進める小さな試作品です。導入の気球を生かし、実際の進行は地図の現在地と景色で表します。地図や街並みはパリをイメージした省略表現で、実際の徒歩経路や距離の再現ではありません。

- **行き先と教材は別々に選択**: 語彙・会話・文法、A1〜C2や上級文法を最初から選べます。教材の難度や正答率による行き先・教材のロックはありません。
- **最初の通常ラウンドは3問、その後は10問**: プロフィールごとの導入です。復習は導入とは別で、対象が1問なら1問、最大10問です。制限時間や速さによる評価はありません。
- **すべての教材で1正解＝旅の進み1**: 語彙・会話・文法・復習を共通に数えます。不正解は増分0で、これまでの進みを減らしません。初期の2つの道は、それぞれ3正解分で到着します。
- **ラウンドと到着を別に管理**: 3問を2正解で終えた場合、旅は2だけ進みます。途中で到着した後の正解分や、行き先を未選択で学習した分は持ち越します。次の道は自動で選ばず、学習パートの外で本人が選びます。訪問済み地点へは戻れます。
- **途中の励ましと相棒の反応**: 演出量は「たっぷり(rich)／ひかえめ(calm)」をプロフィール別に選べ、途中で切り替えられます。問題、採点、進み、報酬条件は共通です。端末の「動きを減らす」設定も優先します。
- **文法のおすすめ順**: 初級・中級・上級の30単元を案内します。単元を自由に選ぶこともできます。「一通り取り組んだ」は各問題に正解または不正解の回答履歴がある状態で、習得認定ではありません。3問の導入だけで10問の単元を完了にしません。
- **日本語の操作案内は漢字とふりがな**: 表示用データで対応し、既存教材の本文や履歴キーは変更していません。

既存の星、12区分の到達度、10%ごとのバッジ、学習記録、復習も引き続き使えます。初回プロフィール選択時の絵入りチュートリアルは2ページあり、ホームから再表示できます。複数都市、歴史クイズ、図鑑、捕獲、進化、着せ替え、乗り物の獲得は、今回の試作には含みません。

### チュートリアルの絵の差し替え
`img/tutorial1.png`(1ページ目)、`img/tutorial2.png`(2ページ目)を置くと自動でその画像が表示されます(jpgの場合はpngに変換するか、index.html内のファイル名を変更)。

## 起動方法

フォルダ内の `index.html` をブラウザで開きます。ビルドや外部ライブラリのインストールは不要です。教材・画像・JavaScriptは同じフォルダ構成のまま置いてください。学習と保存はローカルで動作し、音声はブラウザや端末に用意されたフランス語の声を使います。一部の音声はネット接続を必要とします。

ローカルHTTPプレビューを使う場合は、Python 3がある環境でリポジトリ直下から次を実行できます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

[ローカルプレビュー](http://127.0.0.1:8000/)を開き、確認後はターミナルで `Ctrl+C` を押してサーバーを終了します。これは公開サイトへのデプロイではありません。

**ローカルプレビューと公開サイトは別の保存先です。** 同じブラウザでも、URLの種類・ホスト名・ポート番号が違うと記録は別に保存されます。`localhost` と `127.0.0.1`、別ポート、ローカルファイル、[公開サイト](https://statsbio.com/french-quiz/)の間を移る場合は、JSONの書き出し・読み込みを使います。

## 機能
- **プロフィール4人まで**: 最初の画面で選択/追加。記録は人ごとに別管理
- **クイズ2方向**: 絵+日本語→フランス語 / フランス語→絵+日本語(ミックスも可)。初回の通常ラウンドは3問、その後は10問。文法は穴埋め4択
- **答え合わせ**: ⭕❌と効果音。動きの量は演出設定に従う。他の選択肢の意味・読み方も同時に表示され、外れの単語からも学べる
- **発音**: 🔊ボタンでフランス語音声(名詞は le/la 込みで読み上げ)
- **男性/女性名詞**: 名詞は常に冠詞付きで出題。🔵le / 🔴la のバッジ表示
- **ふくしゅうボックス**: 間違えた単語が自動で入る。クイズ(通常・復習どちらでも)で正解すると自動で外れる。「おぼえた!」ボタンで手動でも外せる
- **きろく**: 日毎の回答数/正解数グラフ(14日分)、語彙・会話・文法の12区分の到達度バー、全員の比較表
- **バッジシステム**: 各区分の到達度10%ごとにバッジ1個(100%超の周回中も継続)。ラウンド終了時に新たな獲得を表示。記録画面に「バッジコレクション」、ホームに合計数、対象を絞った通常ラウンドの結果に次のバッジまでの目安を表示。紙吹雪の条件は正答率80%以上またはバッジ獲得で、ひかえめ設定では動きを抑える
- **到達度の仕組み**: 1回正解で「おぼえた」。区分内の全項目を覚えると2周目開始(バーはリセット、%は101%→200%と累積)。周回は各項目の最低正解回数で判定。ホーム画面には12区分のバーを表示。旅の累積正解数とは別の学習指標
- **設定**: 効果音ON/OFF、カタカナよみがなON/OFF、フランス語音声、演出量
- **出題モード** (ホーム下部の2ボタンで切替): 「🎯覚えていない言葉だけ」(初期設定・現在の周でまだ覚えていない問題を優先) / 「🎲全部からランダム」。未習がその回の出題数に満たなければ、覚えた問題で補う

## データ保存について

- 保存先は従来どおりブラウザの `localStorage["frquiz-v1"]`。同じブラウザ・同じ保存先で記録が残る。プロフィールごとに正誤、日別記録、復習、旅、演出設定を分離する
- **毎回答で保存**: 正誤・復習状態と、その回答で増えた旅の進みを一緒に保存する。途中でやめても保存済みの正解分は失わない
- **クイズの途中状態の完全再開は未対応**: 再読み込み後、残りの問題や選択肢をそのまま再開する機能はない。次は新しいラウンドから始めるが、学習記録・移動途中・持ち越した正解分は残る
- 旧プロフィール・正誤・日別記録・復習データを保持し、新しい旅と文法案内の情報を補う。過去の総正解数を旅へ一括換算しない。文法の取り組み状況には既存の回答履歴を使う
- ホームの「💾保存」でJSONを書き出し、「📂読み込み」で復元する。移動途中、持ち越し、訪問、演出設定、文法の選択情報も含む。読み込みは検証と保存に成功してから現在の記録と入れ替える
- 保存に失敗した場合は画面に案内を出す。保存を再試行するかJSONを書き出し、保存できるまでは画面を閉じない
- 起動時に未知の版の旅・文法案内がある場合は、その情報を保持して該当機能の更新を止める。未対応の版を含むJSONの読み込みは採用しない。壊れた保存データを読み込めない場合も、元の保存内容を自動で上書きしない
- ブラウザ・PC・URL・ポート・ローカルファイルの置き場所を変更する前にJSONを書き出す。公開サイトとローカル試作の記録は自動で同期しない。新版データを旧アプリへ戻して使うことは互換性の保証対象外

## 発音について
- アプリはブラウザ内のフランス語音声だけを選んで使います(英語・日本語の声にはフォールバックしません)
- 自動選択の標準の声は **Audrey (Premium/Enhanced)**(インストール済みなら常に最優先、なければ他の女性のフランス語音声を優先)。別の声にしたい場合はプルダウンから選択
- **声が気に入らない場合**: ホームのプルダウン「🗣️ こえを えらぶ」で端末内の全フランス語音声を試聴して固定できます(選ぶと bonjour, merci と試し読み)。★付きが高音質版
- **重要**: macOS標準で最初から入っているのは「コンパクト版」というロボット風の低音質声だけのことが多いです(どもって聞こえる)。きれいな声にするには:
  システム設定 → アクセシビリティ → 読み上げコンテンツ → システムの声 → 管理 → フランス語 で
  **Audrey (プレミアム)** や **Amélie (拡張)** をダウンロード → ブラウザ再起動 → アプリのプルダウンで選択
- Chromeならネット接続時「Google français」(女性・高音質)も選べます
- いま使われている声はホーム画面の下部に「🗣️ フランスごの こえ: ○○」と表示されます
- 「⚠️ みつからない」と出る場合、そのブラウザにフランス語音声がありません:
  - **macOS**: システム設定 → アクセシビリティ → 読み上げコンテンツ → システムの声 → 管理 で フランス語(Thomas, Amélie など)を追加 → ブラウザ再起動
  - **Chrome** は「Google français」というネット経由の声を使えることもあります(オフライン時は不可)
- 発音が英語風に聞こえた場合は上記の声が未インストールだった可能性が高いです

## 単語の追加方法
`words.js` に1行追加するだけ。例:
```js
{fr:"fantôme",art:"le",g:"m",ja:"おばけ",kana:"ル ファントム",e:"👻",lv:"A1",cat:"あそび",pos:"n"},
```
- 名詞(pos:"n")は `art`(le/la/l'/les)と `g`(m/f)必須。母音・無音h始まりは `l'`
- 既存の `fr`・`ja` は学習履歴キー(`fr::ja`)に使うため、表記を変えると別の項目になる。漢字とふりがなのUIは `ui-ja.js` などの表示側で扱い、既存教材の `ja` を一括で書き換えない
- `kana` は冠詞込みの読み(例: l'eau → ロー)
- B2以降を追加する場合は `lv:"B2"` 等にすれば到達度バーが自動で有効になります
